Hollowetica is a stylish display pixel font recreation based on the original main text font appearing in the video game Mina the Hollower, developed and released by Yacht Club Games in 2026.

The character set of this font includes the full Japanese hiragana and katakana as well as the full Cyrillic character sets and was greatly expanded with countless additional special characters, diacritic variants, unique glyphs and the like, each one of them designed to match the spirit and style of the original font design.

Features

• 837 characters total
• Proportional display typeface
• Full Japanese and Cyrillic alphabets
• Countless additional special characters, diacritic variants, etc.
