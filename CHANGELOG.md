# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено
- Новый враг **Ненасытный** — чёрный кот-демон со своими атаками в духе Undertale и Deltarune:
  «Пасть» (челюсти из клыков захлопываются), «Когти» (три полосы клыков наискосок), «Кошки-мышки»
  (пули бегают по краю рамки и по одной бросаются в сердце), «Чеширская улыбка» (ухмылка проступает
  вокруг сердца, зубы срываются от уголков к середине) и «Прыжки» из засады. Пули — кошачьи головы,
  следы лап и клыки; генераторы графики — `Art/Source/gen_beast*.lua`.
- Сборка для Android (IL2CPP, ARM64, Android 8.0+): пакет `com.LotWyx.BlackHeart`, только горизонтальная ориентация.

- Музыка на паузе замирает и продолжается с того же места (событие `GameEvents.OnPauseChanged`).
- Сид забега: решения боя (враги, атаки, типы и направления пуль) берутся из `GameRandom` с сидом,
  который пишется в лог; `BattleController.Begin(seed)` повторяет забег.
- Автотесты сида, тасовки типов пуль и проверки id атак (всего 17).

### Изменено
- Сохранение атомарное (`File.Replace`); громкость пишется на диск один раз, когда ползунок отпустили,
  и сразу — при сворачивании и выходе.
- Неизвестный id атаки — ошибка в консоли и проверка ассета врага в редакторе (раньше — тихая подмена).
- Пули получают стиль врага от `ProjectileManager.Skin`, а не из `GameManager.I.Battle`.
- Без выделений памяти в горячих местах боя (выбор направления синей пули, `BlueGaps`, распад фиолетовой).

### Исправлено
- Рекорд после смерти от синей пули учитывал счёт без штрафа −25: штраф теперь начисляется до урона,
  а рекорд записывается в конце смерти по итоговому счёту.
- Быстрая пуля при просадке FPS могла «перепрыгнуть» сердце: попадание проверяется по пути за кадр.
- На Android не начинались бой и обучение: при сборке IL2CPP Unity вырезал модуль `SpriteMask` (создаётся только
  из кода), и `BattleBox` падал при создании. Вырезание кода движка (Strip Engine Code) отключено.

## [0.2.0] — 2026-10-13

### Добавлено
- Высокая сложность: каждая атака либо «много, но медленно» (больше фиолетовых), либо «быстро, но мало синих».
- Очередь к сердцу: одновременно у сердца не больше 5 одиночных пуль, остальные ждут на границе зоны.
- Зигзаг-пуля со средней сложности: мечется по рамке, фора отсчитывается с входа в рамку.
- Курсор-клинок; во время разреза лезвие краснеет.
- Автотесты (EditMode), CI на GitHub Actions, шаблоны Pull Request и задач, `CONTRIBUTING.md`.
- Плавные затемнения между экранами; пункт «Настройки» в меню паузы.
- Микшер звука с отдельными группами для музыки и эффектов.

### Изменено
- Производительность: пулы пуль, искр и надписей, кэш текста, атласы спрайтов, ограничение FPS
  (240 на ПК, 60 на телефонах).
- Враги и баланс — в ScriptableObject-ассетах (`Assets/Resources/Data`), сохранения — единый `save.json`.
- Числа темпа атак, очереди и зигзаг-пули вынесены в `GameBalance.asset`.
- Структура: код игры — `Assets/Scripts/Runtime` (сборка `BlackHeart.Runtime`), редактор — `BlackHeart.Editor`,
  тесты — `Assets/Tests`; сцена `SampleScene` переименована в `Game`.
- Пакет `unity-mcp` закреплён на конкретной версии.

### Исправлено
- Разделение фиолетовых пуль.
- Откат коммита «optimize2», в котором не хватало префабов атак (враги оставались без атак).

## [0.1.0] — 2026-10-13

Первая публичная сборка для Windows.

### Добавлено
- Бой: защита (разрезать белые и фиолетовые атаки, не трогать синие) и атака по врагу.
- Враги Безликий, Всевидящий, Пустоглазый со своими наборами атак; обучение с Луноликим.
- Вступление в духе Undertale, главное меню, пауза, настройки громкости, рекорд.
- Музыка для вступления, меню, боя и экрана поражения.
