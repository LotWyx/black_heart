# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено
- Высокая сложность: каждая атака либо «много, но медленно» (больше фиолетовых), либо «быстро, но мало синих».
- Очередь к сердцу: одновременно у сердца не больше 5 одиночных пуль, остальные ждут на границе зоны.
- Зигзаг-пуля со средней сложности: мечется по рамке, фора отсчитывается с входа в рамку.
- Курсор-клинок; во время разреза лезвие краснеет.
- Автотесты (EditMode), CI на GitHub Actions, шаблоны Pull Request и задач, `CONTRIBUTING.md`.

### Изменено
- Числа темпа атак, очереди и зигзаг-пули вынесены в `GameBalance.asset`.
- Структура: код игры — `Assets/Scripts/Runtime` (сборка `BlackHeart.Runtime`), редактор — `BlackHeart.Editor`,
  тесты — `Assets/Tests`; сцена `SampleScene` переименована в `Game`.
- Пакет `unity-mcp` закреплён на конкретной версии.

### Исправлено
- Откат коммита «optimize2», в котором не хватало префабов атак (враги оставались без атак).

## [0.1.0] — 2026-10-13

Первая публичная сборка для Windows.

### Добавлено
- Бой: защита (разрезать белые и фиолетовые атаки, не трогать синие) и атака по врагу.
- Враги Безликий, Всевидящий, Пустоглазый со своими наборами атак; обучение с Луноликим.
- Вступление в духе Undertale, главное меню, пауза, настройки громкости, рекорд.
- Музыка для вступления, меню, боя и экрана поражения.
